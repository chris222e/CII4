# 📦 Módulo de Proveedores - Proyecto CII4

## 📌 Descripción

En este módulo se implementó la gestión básica de proveedores, permitiendo registrar nuevos proveedores y listar los existentes en el sistema.

---

## ⚙️ Funcionalidades implementadas

* ✅ Registro de proveedores
* ✅ Listado de proveedores

---

## 🧾 Campos del proveedor

* Nombre
* Contacto
* Teléfono
* Email

---

## 🔒 Validaciones aplicadas

* Teléfono:

  * Solo números
  * Máximo 9 dígitos

* Email:

  * Formato válido
  * Único (no repetido)

* Campos obligatorios:

  * Nombre
  * Contacto

---

## ⚡ Tecnologías utilizadas

* PHP (CodeIgniter 4)
* HTML / CSS
* JavaScript
* MySQL
* Git y GitHub
